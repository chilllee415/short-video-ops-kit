# Short Video Ops 对外发布稿

## 一句话介绍

Short Video Ops 是一套可审计、可白标、数据与系统分离的短视频运营工作流：从账号诊断、策略边界、选题证据、参考拆解，到执行计划和发布反馈，让每个结论都能追溯到策略、信号与证据。

## 它解决什么问题

多数内容工具直接从“生成一批选题”开始，结果往往是泛题、撞题和不可复盘。Short Video Ops 先建立账号与用户的数据脊柱，再进入内容生产：

```text
账号数据 -> 策略评估 -> 选题信号 -> 双候选池 -> 参考拆解 -> 执行计划 -> 页面校验 -> 发布反馈
```

核心区别：

- 正式选题必须带 `strategy_id`、`strategy_assessment_id`、`search_scope_ids` 和 `signal_ids`；`pain_id` 可选。
- 参考内容只借结构，不决定账号方向，也不复制原文。
- 反馈可以提出策略变化，但不能自动覆盖用户确认的策略。
- 系统仓与客户 workspace 分离，支持多客户隔离和白标交付。
- 每次运行留下输入、输出与 run manifest，方便复盘和交接。

## 当前版本包含

- 16 个工作流契约与依赖图。
- 18 个离线/联网 CLI，覆盖校验、大盘、参考挖掘、选题、文案匹配与页面渲染。
- personal / commercial 两种运行策略。
- JSON Schema、workspace 模板、合成示例和离线发布审计。
- 运营大盘 P2「找选题」：策略评估、信号覆盖、6:4 双候选池、2+1 日更选择、详情抽屉与候选滚动列表。

## 适合谁

- 希望把短视频运营变成可复用流程的创作者或团队。
- 为客户提供账号诊断、内容策划或代运营服务的交付团队。
- 需要在本地/私有环境处理账号数据的 AI Agent 项目。

## 开源版与商业版边界建议

社区版保留数据契约、工作流、离线脚本、模板和发布审计。商业能力可以建立在同一数据脊柱上，包括：

- 托管式平台数据采集与定时任务。
- 多租户权限、workspace 管理与审计后台。
- Agent/API 写回、审批和团队协作。
- 品牌化大盘、客户报告与交付模板。
- 第三方数据源、ASR、模型与发布平台连接器。

不建议把客户数据、个人素材库、内部提示资产或平台凭据放进公共仓库。

## 当前成熟度

当前建议标记为 `0.1 beta`。P2 的查看和本地交互已通过验收，但完整商业闭环仍需要补齐：多平台统一采集、06 脚本规划 CLI、07 反馈学习 CLI，以及页面备选通过 API 写回 workspace。

## 发布门禁

1. 运行 `python3 scripts/audit_public_release.py`。
2. 确认仓库不包含真实 workspace、个人路径、账号身份或密钥。
3. 使用全新 commercial workspace 完成一次 smoke test。
4. 选择并加入正式 `LICENSE`。
5. 标明第三方 API、模型与平台条款由部署者自行配置和遵守。

本项目采用 Apache-2.0，允许商用、修改和 SaaS 集成。再次分发修改版本时必须保留 `LICENSE`、`NOTICE` 和版权声明，并明确哪些文件被修改。该许可证不授予项目名称或商标的使用权。
