## 核心闭环

| 环节 | 当前状态 | 公开版边界 |
| --- | --- | --- |
| 看账号 | 可用 | 支持规范化快照、作品表现和执行约束；平台登录采集需自行接入 |
| 评估方向 | 可用 | 只能继续、优化执行、验证实验或提出复核建议；不会自动覆盖已确认策略 |
| 找选题 | 可用 | 生成 6 条保守 + 4 条激进候选，并选择 2+1 日更组合；要求机会信号血缘 |
| 找爆款并拆解 | 可用 | 按正式候选逐题找参考，学习结构、证明和 CTA；联网下载可选 TikHub/ASR |
| 做计划 | 可用 | 合并选题、参考结构和运营约束，生成 3 条执行计划 |
| 更新页面 | 可用 | 构建 JSON、渲染固定 HTML、校验候选完整性和页面契约 |
| 发布回流 | 契约可用 | 能保存反馈和下一轮输入；公开版不含平台自动发布或登录采集器 |

## 16 个工作流契约

公开版包含 16 个有效 manifest，覆盖：账号诊断、选题证据整理、策略确认、参考研究计划、脚本/转录采集、参考拆解、参考入库、统一候选编排、保守候选池、激进候选池、2+1 选择、脚本计划、文案优化、发布反馈和每日闭环。

Skill 与工作流的分工不同：Skill 保存可复用的判断政策；manifest 保存固定节点的输入、输出、依赖和禁止行为。详见 [`../skills/README.md`](../skills/README.md)。
