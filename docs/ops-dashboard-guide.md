# 运营大盘里每一块在做什么

运营大盘不是单独的一张报表，而是把每天的运营判断收在一个页面里。它回答四个普通人也能直接行动的问题。

| 大盘区域 | 它回答的问题 | 对应工作流 |
| --- | --- | --- |
| 看账号 | 最近的数据哪里变好了，哪里需要调整？ | `01-auto-ops-diagnosis` |
| 找选题 | 账号当前方向里，哪些用户关注、搜索趋势、行业热点和内容缺口值得拍？ | `02-pain-bank-builder`、`05-topic-candidates` |
| 拆爆款 | 有哪些内容结构值得研究，而不是照抄？ | `04-reference-mining`、`04a` 至 `04d` |
| 出动作 | 今天先做哪个选题，怎么安排脚本和发布？ | `03-strategy-confirmation`、`06-script-planning`、`07-feedback-learning` |

## 每天怎么用

1. 更新账号数据和最近作品表现。
2. 把新评论、咨询或市场信号补进工作区。
3. 运行大盘更新命令。
4. 先看“今日动作”，再决定今天拍什么、怎么写、发布后看什么。

```bash
python3 scripts/update_ops_dashboard.py /path/to/your-workspace
```

## 你不需要一次填完所有资料

刚开始只要有账号定位、最近几条内容表现和一些用户问题，就可以先生成第一版。后续再逐步补充竞品参考、痛点库和发布反馈，大盘会越来越贴合你的账号。

## 真实数据放在哪里

项目代码在 GitHub，真实账号数据放在你自己电脑上的工作区。不要把以下内容上传到公共仓库：

- 创作者平台导出、评论、私信和客户资料。
- API Key、Cookie、账号密码。
- 未公开的视频素材和内部复盘。

公开项目只保留工作流、Skill、页面模板、示例结构和安装说明。
