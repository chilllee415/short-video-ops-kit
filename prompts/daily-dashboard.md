# 复制给 Codex：更新今天的运营大盘

```text
请在这个 Short Video Ops 项目里更新我的运营大盘。

我的工作区路径是：<替换成你的工作区路径>

请按下面的顺序做：
1. 先阅读 AGENTS.md 和与今日大盘相关的工作流说明。
2. 先检查 config/profile/ 和 config/strategy/strategy-brief.json。若账号定位或运营策略缺失、仍是模板示例或尚未由我确认，请先向我提问并等待确认；确认前不要找选题、拆爆款、写文案或生成 ready 计划。
3. 确认后，检查我今天提供的账号数据、作品数据、评论或已有工作区资料。
4. 不要编造缺失的数据；缺什么就明确告诉我。
5. 更新必要的工作区数据后，生成运营大盘 HTML。
6. 最后用普通话告诉我：账号最重要的一个信号、今天最值得做的内容动作、还缺什么数据。
```

> 提示：如果你希望 Codex 去读取已登录的创作者平台，请先在本机浏览器完成登录，并明确授权它查看对应账号的数据。
