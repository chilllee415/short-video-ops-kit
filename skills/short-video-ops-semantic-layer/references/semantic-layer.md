# Semantic layer

| Level | Entity | Meaning | May affect | Must not be used as |
| --- | --- | --- | --- | --- |
| L0 | Account identity | Audience, offer and durable positioning | Strategy boundary | Daily diagnosis |
| L1 | Confirmed strategy | Direction, tracks, principles and exclusions | Topic search scope | A daily topic |
| L2 | Operating data | Published-content performance and feedback | Execution and topic-mix tuning | Proof of audience demand |
| L3 | Topic evidence | Pains, search intent, trends, market tasks and content gaps | Candidate topics | Benchmark content |
| L4 | Candidate topics | Ranked responses to evidence inside strategy | Benchmark search and selection | Strategy |
| L5 | Benchmark content | Existing supply-side content | Hook, structure, proof and CTA patterns | Demand proof |
| L6 | Execution plan | Production and publishing actions | Production | Source evidence |
| L7 | Publish feedback | Results after execution | Next operating cycle | Automatic strategy replacement |
| L8 | Presentation | Dashboard JSON and HTML | Human review | Source of truth |

## Daily dependency order

```text
operating data -> execution constraints
confirmed strategy -> search boundary
strategy boundary + topic evidence -> candidate topics
candidate topics -> benchmark research
topics + benchmarks + constraints -> plan
plan -> dashboard JSON -> HTML verification
published results -> next operating cycle
```

Common category errors: low retention is not a user pain; a popular creator post is not demand proof; a named content idea is not an account stage; a page headline is not strategy; modification time is not the business date.
