# Evidence audit

For every recommended topic verify:

1. It is inside a confirmed strategy search scope.
2. It links to a current strategy assessment.
3. At least one linked signal is an accepted opportunity role: `audience_pain`, `search_interest`, `hot_topic`, `industry_signal`, `market_task`, or `content_gap`.
4. Operating metrics only tune execution or ranking.
5. Benchmark content was collected after candidate creation and is used only for expression patterns.
6. The plan, dashboard JSON, and HTML are not upstream proof.
7. Data dates, source coverage, and blockers are visible.

If any required lineage is missing, return `blocked`; do not recycle an old topic as current evidence.
