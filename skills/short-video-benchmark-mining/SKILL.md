# Short-video benchmark mining

Find expression references for formal topics. Do not create or change topics.

## Inputs

Read the workspace manifest, selected topics, confirmed strategy, benchmark-mining policy, current reference bank, and operating constraints. Require topic lineage and an explicit source date. Never use the dashboard as input.

First verify that the manifest-declared account positioning and strategy are complete and explicitly user-confirmed. If either is missing, still a public-template example, lacks confirmation provenance, or is unconfirmed, ask the user to complete onboarding and stop. Do not infer positioning or strategy from a selected topic or popular reference.

## Process

1. Create a separate search plan for each selected topic.
2. Expand each topic into at least three query forms: audience problem, concrete task/result, and likely content phrasing.
3. Check at least two available sources. Record unavailable sources instead of inventing coverage.
4. Keep only references whose content can be inspected beyond a title or thumbnail.
5. Score each reference on topic relevance, performance evidence, transferability, evidence completeness, and copying risk. Do not compare raw engagement counts across platforms as if they were equivalent.
6. Select up to three complementary references per topic; avoid three copies of the same structure.
7. Deconstruct hook, first proof, retention device, structure, pacing, CTA, reusable pattern, and elements that must not be copied.

## Output

Write only manifest-declared benchmark outputs. Preserve source URL or ID, platform, observed date, visible metrics, transcript availability, topic ID, score breakdown, transferable patterns, and prohibited-copy notes. Return `blocked` for a topic when no inspectable, relevant reference exists.

## Boundaries

- Popular content is `supply_content`, not proof that users want the topic.
- Search benchmarks only after candidate selection.
- Copy structure, not wording, media, numbers, author stories, or unsupported claims.
- Do not alter strategy, topic pools, topic selection, plans, scripts, or HTML.
