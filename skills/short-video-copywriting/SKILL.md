# Short-video copywriting

Produce one truthful, shootable script from an already selected topic.

## Inputs

Read the workspace manifest, selected topic, topic-specific benchmark deconstruction, account profile, confirmed strategy, operating constraints, available first-person proof, and publishing goal. If a draft exists, diagnose it before rewriting.

First verify that the manifest-declared account positioning and strategy are complete and explicitly user-confirmed. If either is missing, still a public-template example, lacks confirmation provenance, or is unconfirmed, ask the user to complete onboarding and stop. Do not infer the account voice, positioning, or strategy from a draft, selected topic, benchmark, or dashboard.

## Process

1. Lock the intent: audience, problem, promised result, available proof, desired next action, target duration.
2. Separate verified facts from assumptions. Remove claims that cannot be demonstrated or qualified.
3. Draft three meaningfully different hooks: result-first, problem-first, and tension/contrast. Choose the strongest fit rather than concatenating them.
4. Build the spoken sequence: hook -> scene/problem -> visible proof -> essential method -> limitation or tradeoff -> CTA.
5. Borrow only named structural patterns from the reference deconstruction.
6. Convert paragraphs into short spoken beats and attach simple screen or camera actions where proof should appear.
7. Read the script aloud conceptually: remove repetition, abstract filler, unexplained jargon, and CTA mismatch.

## Output

Write only manifest-declared script or plan outputs. Return the chosen hook, timed spoken beats, proof cue, shot/screen action, CTA, estimated duration, borrowed patterns, unsupported-claim check, and blockers. Preserve the user's core storyline when revising.

## Boundaries

- Do not change account positioning, confirmed strategy, selected topic, or source evidence.
- Do not invent performance numbers, customer cases, personal experience, product capability, or quotations.
- Do not reproduce reference wording.
- Return `blocked` when the topic promises a result that available proof cannot support.
